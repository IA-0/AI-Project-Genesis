1. Existe un repo público en GitHub con el output generado por Atlas para un caso de uso real (spec funcional, arquitectura, backlog priorizado en Markdown).
2. La generación es reproducible: un comando corre el pipeline end-to-end desde la frase de entrada.
3. El post de LinkedIn mostrando el antes/después está publicado, con fecha ≤ 2026-07-10.

Si el 2026-07-10 alguno de los tres no se cumple, `docs/adr/ADR-0001.md` se revisa explícitamente — no se corre la fecha en silencio.
